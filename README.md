# Muhammed Afsal Creator Website

A responsive static website based on the supplied creator homepage design.

## Files
- `index.html` — page content and social links
- `style.css` — responsive layout and styling
- `script.js` — mobile navigation and current year
- `assets/` — image crops from the supplied design reference

## Before publishing
1. Open `index.html`.
2. Replace every example `https://www.youtube.com/` with your actual public YouTube channel URL.
3. Replace every example `https://www.instagram.com/` with your actual Instagram profile URL.
4. Replace every example `https://www.facebook.com/` with your actual Facebook page/profile URL.
5. Replace `hello@example.com` with an email address you want visitors to contact.
6. Replace the example video links with the corresponding YouTube video URLs.
7. Update the giveaway/challenge text and rules before announcing any real prize.

The website only links to public social profiles. It does not ask visitors for social-media passwords, OTPs or login credentials.

## Publish with GitLab Pages
1. Create a new blank project in GitLab.
2. Upload the contents of this folder to the repository root (not the parent folder).
3. Ensure `index.html` is in the repository root.
4. The included `.gitlab-ci.yml` deploys the static site using GitLab Pages.
5. In GitLab, open **Build > Pipelines** and wait for the pipeline to pass.
6. Open **Deploy > Pages** to find your published website URL. GitLab may ask you to enable Pages for the project.

You can edit the files locally and push updates to GitLab whenever you want.
